# Forkcast

Plan lunch with your colleagues: recommend restaurants, vote on today's spot, organize office cooking and coordinate food orders.

Forkcast is a self-hostable Expo/React Native app with an installable web app (PWA), English/German translations and system dark mode. Supabase provides authentication, data, images and live updates.

- **Lunch overview:** team attendance, today's plan, restaurant votes and a wheel picker.
- **Places:** map/list views, reviews, favorites, cuisine filters and walking distances.
- **Cooking and orders:** signups, deadlines, comments and payment tracking.
- **Organizations:** invitations, multiple administrators and member management.
- **Notifications:** in-app inbox and optional device Web Push.
