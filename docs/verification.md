## Reproduce

```sh
npm run check
npm run edge:check
npm run edge:test
npm run format:check
npm run export
npm run test:ui:build
npx playwright install chromium
npm run test:ui
```

Python 3 serves browser tests on loopback port 8088. `FORKCAST_CHROMIUM_PATH` may select an existing Chromium binary. The test build uses explicitly fake Supabase credentials and lives in `/tmp/forkcast-test-web`; `.env` is not overwritten. `npm ci` prepares the version-matched browser worker and license.

The optional Postgres integration suite needs a disposable server. See README. It creates `forkcast_test` and refuses to overwrite an existing database. Restart the disposable container before another run. Tests skip by default when `FORKCAST_TEST_DATABASE_URL` is absent.
